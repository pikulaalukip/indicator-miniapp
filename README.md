# INDICATOR Mini App

Telegram Mini App для индикатора INDICATOR (TradingView).

- Живой график BTC 1W со свечами Binance в реальном времени (REST + WebSocket) на Lightweight Charts.
- Логика индикатора перенесена на JavaScript: сигналы ATR-трейлинга, уровни TP1–TP3 / SL (проценты или R), профиль объёма POC / VAH / VAL, статистика последних 30 сделок.
- Экраны: главная, как читать график, анализ монеты (1 в неделю за подписку), тарифы, оплата через CryptoBot, ник TradingView, профиль.

Оплата и проверка подписки в этой версии имитируются в браузере. Настоящие появятся вместе с сервером бота.

Хостинг: GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
